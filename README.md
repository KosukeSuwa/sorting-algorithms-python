# sorting-algorithms-python

## 実装したソートアルゴリズムとその理由
- 選択ソート ([selection_sort.py](./selection_sort.py))
  - 自分にとって最も直感的に理解しやすく、人が何かを並び替えようとしたときに最初にパッと思いつく方法に近いと思い、個人的に好みです。
- マージソート ([merge_sort.py](./merge_sort.py))
  - 入力データの初期状態に左右されにくく、最悪の場合でもO(nlogn)の計算量が保証されている点で処理時間が安定していて予測しやすい点が好みです。実際のシステムにも導入しやすそうと感じました。
